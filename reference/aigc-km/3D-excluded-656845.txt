AI摘要: **文章摘要**

本文系统介绍了腾讯在长视频动作驱动生成领域的技术实践，重点解决了现有视频扩散模型无法生成长时间视频的核心问题。文章从背景瓶颈分析入手，提出了一套包含六步的完整流水线方案，通过全局骨骼驱动、零样本自动分割、双轴时序平滑等创新技术，实现了骨骼一致性、背景稳定性和特效合成的全面提升。最后通过对比现有工作和效果总结，展示了该方案在AI舞蹈/运动视频生成等场景的应用价值。

**文章重点总结**

1. **问题背景与解决思路**：
   - 当前视频扩散模型（如Wan2.2）受限于错误累积，仅能生成10-30秒短视频，长视频会出现背景变色、人体畸变等问题。
   - 文章提出分段生成再拼接的思路，并系统性解决了段间骨骼坐标不一致、背景风格割裂、前景分割依赖人工、特效中心高频抖动四大工程难题。

2. **核心技术方案**：
   - **全局骨骼驱动**：一次性提取完整视频骨骼（ViTPose wholebody ONNX），确保所有帧关键点处于同一坐标系，从源头消除跳变。
   - **骨盆关键点对齐**：通过检测各段第一帧骨盆关键点，平移前景区域补偿扩散模型生成的随机漂移。
   - **零样本自动前景分割**：基于GroundingDINO和SAM2构建级联链路，通过覆盖率（衡量漏分）和溢出率（衡量过分割）双指标实现自反馈精化，将标注工作量从O(N)降至O(1)。
   - **双轴差异化时序平滑**：针对X轴（低频随动）和Y轴（高频抖动）不同物理特性，采用差异化滤波窗口（X轴~0.15s，Y轴~1.0s），使Y轴抖动降低80%。
   - **工程可用性设计**：支持增量复用（跳过步骤、复用中间结果）、SAM可视化调试和多候选生成，提升实操效率。

3. **效果与对比**：
   - 相较Animate Anyone、MimicMotion等方案，本方法在长视频能力、骨骼一致性、自动分割和特效合成方面均表现更优。
   - 核心收益包括骨骼一致性、背景一致性、分割自动化和特效稳定性，适用于AI舞蹈生成、短视频特效增强等场景。

正文: 一、背景：短视频扩散模型的天花板
当前主流的视频扩散模型（如 Wan2.2）在骨骼驱动的人物视频生成上已经能产出相当高质量的结果——但有一个绕不过的瓶颈：它们只能生成 10 - 30秒左右的短片段。
根本原因长视频推理中的错误累积，超过时间的长视频，就会出现背景变色、模糊、人体畸变等问题，导致长时间的视频生成完全不可用。

那能不能"分段生成再拼接"呢？思路对，但工程上有几个棘手问题：

问题现象
段间骨骼坐标不一致每段独立估计骨骼，坐标系不统一，拼接处人物位置跳变
背景风格割裂各段生成背景随机差异，拼接后背景像"幻灯片切换"
前景分割依赖人工每段视频都需手动标注 SAM 提示点，N 段就要标 N 次
特效中心高频抖动逐帧独立估计特效锚点，Y 轴 1~3 Hz 高频颤抖

这套流水线的目标，就是系统性地解决上述全部问题。

三、创新点详解
3.1 全局骨骼驱动：从源头消除段间跳变
传统方案的问题：

# ❌ 分段截取 + 独立估计骨骼（存在跳变问题）
def align_pose_segments(segments):
base_pelvis = get_pelvis(segments[0][0]) # 第1段第1帧
for seg in segments[1:]:
cur_pelvis = get_pelvis(seg[0])
dx = base_pelvis.x - cur_pelvis.x # 累积检测误差
dy = base_pelvis.y - cur_pelvis.y # 段间残余抖动仍存在

问题在于：每段独立估计的骨骼坐标系本来就不统一，再做对齐也只是"事后补救"，误差累积不可避免。
本方案的解法：
对完整原始长视频一次性运行预处理，调用 ViTPose wholebody ONNX 对全段逐帧估计骨骼，写入 src_pose.mp4。所有帧的关键点天然共处于同一坐标系，分段切片时不做任何空间变换，从源头杜绝坐标系不一致。

完整视频 → 一次性骨骼提取 → 全局统一坐标系
↓
按 10s 窗口切片（仅时间轴截取，不变换空间坐标）
↓
各段以切片骨骼 + 人脸参考 → 分段生成

3.2 微观补偿：骨盆关键点对齐
全局骨骼驱动解决了"宏观"坐标一致性，但扩散模型生成过程本身存在随机的人物位置漂移（这是生成模型的固有特性）。
Step 5 用 ViTPose 检测各段第一帧的骨盆关键点（左/右髋关节中点），以第一段为基准计算各段偏移量，仅平移前景区域，背景原位不动，消除残余漂移。
宏观全局骨骼驱动 + 微观骨盆平移补偿 = 宏微观双层空间一致性保障
3.3 零样本自动前景分割：双指标自反馈精化
这是本流水线里我个人认为最有独立工程价值的模块。
核心级联链路：

文本提示（如 "person ."）
↓
GroundingDINO 开放词汇检测 → 边界框
↓
SAM2 首帧分割 → mask
↓
双指标质量评估
↓ （若不合格）
自动正/负点补充 → 重新分割
↓
SAM2 视频传播 → 全段 mask 序列

双指标设计的关键洞见：
传统方案用"矩形 IoU"评估分割质量，但人体是高度非矩形的——人体实际面积只占检测框的 40~60%。用矩形 IoU 会系统性低估覆盖率，触发大量冗余精化。
我们设计了两个正交指标：

指标定义衡量什么
覆盖率（Coverage）检测框内 mask 像素 / 检测框总面积漏分程度（低 = 漏分多）
溢出率（Overflow）框外 mask 像素 / 总 mask 像素过分割程度（高 = 背景侵入多）

自反馈精化逻辑：

if coverage < 0.25: # 漏分 → 补正点
add_positive_point(center_of_uncovered_region)
if overflow > 0.30: # 过分割 → 补负点
add_negative_point(center_of_outside_mask)

这个闭环设计让处理 N 段视频的标注工作量从 O(N) 降至 O(1)——只需一次文本输入，剩下的全自动完成。

3.4 双轴差异化时序平滑：让特效中心稳下来
舞蹈/运动视频中，人物重心在 Y 轴有 1~3 Hz 的高频起伏（跳跃、颠步），在 X 轴只有低频的左右随动。如果特效中心（射线发射点）直接跟随重心，会产生明显的"颤抖感"。
关键洞察：X 轴和 Y 轴的物理特性不同，要分别对待。

def smooth_centers(centers, fps=30):
xs = [c[0] for c in centers]
ys = [c[1] for c in centers]

win_x = max(3, int(fps * 0.15)) | 1 # ~0.15s，保留左右随动感
win_y = max(15, int(fps * 1.0)) | 1 # ~1.0s，滤除高频抖动

# reflect 填充避免端点衰减
return smooth_axis(xs, win_x), smooth_axis(ys, win_y)

效果：Y 轴抖动幅度降低约 80%（等效低通截止频率 ~0.5 Hz，有效过滤 1~3 Hz 成分），同时 X 轴保留自然的左右跟随感。
