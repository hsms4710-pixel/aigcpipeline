0.2信息流广告：一场"素材消耗战"

核心公式
投放效果 = 素材质量 × 素材数量 × 投放策略。素材是广告效果的第一变量，也是最大的生产瓶颈。

为什么素材是第一变量？分享人给了四个理由：

算法驱动机制——平台算法高度依赖 CTR/CVR，优质素材是触发推荐、获取流量池的先决条件；ecpm、3 秒毛玻璃达不到，广告甚至出现不到用户面前。

用户注意力稀缺——信息流里用户停留极短，前 3 秒的视觉冲击与痛点抓取直接决定广告生死。

素材生命周期缩短——高频曝光导致审美疲劳，单一素材有效衰退期已从"按周"缩短到"按天"。

越竞争越激烈——大家都在大量做素材，周期只会越来越短。

PART 1 · Harness 理念重塑

思维重塑：什么是 Harness 与 Multi-Agent 协作

从提示工程（Prompt Engineering）到驾驭工程（Harness Engineering）的思维升级，以及为什么 Multi-Agent 特别适合创意素材生产这类复杂任务链。

1.1从"用 AI"到"驾驭 AI"的三个阶段

STAGE 01会用 AI把 AI 当简单问答工具，停留在基础对话交互，缺乏系统性应用。

STAGE 02Prompt Engineering精心设计提示词获取更好结果，但高度依赖人的经验、精力与时间——核心痛点是"人是瓶颈"。

STAGE 03Harness Engineering构建系统和框架，让 AI 能自主规划、执行、优化任务，实现自动化闭环——这是今天的主题。

思维升级
从"我怎么让 AI 做得更好"，到"我怎么设计一个让 AI 自己做好的系统"。

1.2Harness Engineering：驾驭，而非操控

Harness = 马具 / 驾驭，Engineering = 工程化（可重复、可扩展）。Agent = Model + Harness：模型负责推理，Harness 负责调度、约束、记录。对比两种范式：

维度
Prompt Engineering
Harness Engineering

角色定位
人 = 操作者
人 = 架构师

AI 的角色
AI = 工具
AI = 协作者

工作方式
人驱动 AI
AI 驱动 AI

扩展方式
人力线性扩展
系统弹性扩展

质量保障
人工审核
系统自检

工匠的产出受个人能力限制，工厂的产出受系统设计限制 —— 而系统是可以持续优化的。—— Harness 理念的核心比喻

1.3Multi-Agent：让专家团队替你干活

单 Agent（全能型）要求一个模型掌握所有技能，处理复杂任务时容易幻觉、逻辑混乱或遇到能力瓶颈；Multi-Agent（专家团队）把复杂任务拆解，由多个特定角色的"专家"Agent 分工协作，显著提升稳定性和输出质量。三大核心协作模式：

串行 Pipeline

流水线作业，上一个 Agent 的输出作为下一个的输入。适用于步骤明确、依赖强的线性任务。

并行 Parallel

同时处理不同子任务，最后由汇总 Agent 整合。适用于可独立拆分、互不干扰的宽泛任务。

反馈循环 Feedback

包含执行者与评估者，不合格则打回重做直至达标。适用于需要高精度和自我纠错的任务。

关键原则
一个 Agent 做一件事，做到极致，才更容易出精品。

1.4素材生产天然就是一条任务链

素材生产每个环节都能定义明确的输入和输出，且各有不同的能力要求——这正是它适合 Multi-Agent 的原因：

策略分析（输入：产品信息+目标 → 输出：策略简报）｜能力：营销知识、用户洞察、传播判断

文案创作（输入：策略简报 → 输出：配音文案）｜能力：创意发想、语言表达、卖点提炼

脚本编写（输入：文案+方向 → 输出：结构化分镜脚本）｜能力：视频叙事、镜头感、节奏控制

画面生成（输入：分镜描述 → 输出：图片/视频素材）｜能力：Prompt 撰写、视觉描述、风格控制

剪辑合成（输入：素材+时间轴 → 输出：合成视频）｜能力：镜头编排、节奏感、后期处理

质检审核（输入：成品素材 → 输出：评估和分析）｜能力：逻辑校验、风险识别、事实核查

范式沉淀
经验会过时，但框架会沉淀；模型会升级，但系统能力会累积。用健壮的工程架构去弥补底层模型的缺陷。

2.1我们的素材工厂：Agent 矩阵全景

整个矩阵是一个闭环有向图：调度 Agent 负责任务分发与统筹；核心生产矩阵由策略→文案→编剧→画师→剪辑→质检六个 Agent 组成；产出成品投放后，效果分析 Agent 做数据回收与归因。两个反馈循环让系统越用越聪明——

局部反馈：质检不通过时打回重做与修正（Agent 内 / 相邻 Agent 之间）

全局反馈：投放数据驱动策略迭代（对应 Part 4 的 Loop 归因闭环）

全景一句话
这是一个闭环有向图：两个反馈循环让系统越用越聪明。

2.2调度 Agent：从"通用大脑"到"业务专属流程"

理想设计是依赖大模型作"通用大脑"，运行时动态拆解任务、规划路径。但现实挑战很大：动态规划不可控且易幻觉、复杂任务多轮思考耗时长、真实业务容错率极低。因此实际落地方案改为业务专属流程：

预设标准节点——将高频业务任务固化为标准执行节点，大幅减少动态生成的算力开销

明确条件分支——结合规则引擎或轻量级模型判断，实现流程精准流转与状态控制

人机协同机制——在关键决策节点引入人工确认（Human-in-the-loop），确保业务流转绝对安全

核心思路
把任务拆解从"运行时"移到"设计时"——用确定性换取可靠性。

2.3策略 Agent：从产品信息到创意方向

职责链路：输入（用户原始需求、产品文档、历史效果数据）→ 处理（提炼核心卖点、分析目标受众痛点、匹配传播渠道特性）→ 输出（标准化《创意策略简报》）。策略简报片段示例：目标受众"25-35 岁一二线城市职场白领"，核心卖点"AI 一键生成，节省 80% 重复劳动时间"，创意调性"专业可靠、富有科技感，同时轻松幽默"。

链路宪法
策略简报是后续所有 Agent 的"宪法"——保证整条链路方向一致。

2.4文案 Agent：视频广告的"声音"从这里来

文案 Agent 不是写作文，广告文案有明确的营销手法。四项核心职责：

解析商品卖点——把产品核心优势转化为用户易懂的口语化表达

构建叙事结构——设计"黄金三秒"开头、痛点引入、卖点阐述、转化号召的完整逻辑链

匹配情感基调——按受众画像与平台特性动态调整语气（专业严谨 / 亲切幽默 / 紧迫促销）

控制视频节奏——通过字数预估与断句设计，精准把控画面切换频率与整体时长

叙事主线
配音文案决定视频的情感节奏——它是整条链路的叙事主线。营销手法（开头钩子→转折点→对比论证→收尾 CTA）是它区别于普通文本创作的最大差异点。

2.5编剧 Agent：从文案到可执行的视频脚本

三项职责：语义转换（把抽象营销文案转化为具象视听语言）、分镜规划（规划每个镜头的画面、机位运动、旁白台词、背景音效）、格式规范（严格按预设 Schema 输出 JSON，确保下游无缝解析）。

工程化关键
结构化输出是工程化的关键——脚本可被后续 Agent 直接解析，减少转换损耗。

2.6画师 Agent：Prompt 工程师 + 视觉一致性守护者

四步工作流：① 解析分镜需求（提取主体、场景、光影、构图）→ ② 匹配角色资产（调用角色库获取标准描述词与参考图）→ ③ 组装 Prompt（融合分镜要素与角色资产，符合目标模型语法）→ ④ 质量校验与迭代（预检合规性，按结果微调重绘）。

核心机制
人物描述必须引用参考图——这是保障跨镜头角色一致性的关键机制。首帧提示词聚焦静态内容、避免动态描述；视频提示词描述动态内容——静与动组合成完整片段描述。

2.7画师 Agent：如何保持图片素材的丰富度

三种解法互补叠加，价值随时间复利增长：

解法一：大模型自主创作

✅ 成本低、速度快
❌ 多样性受 Prompt 质量影响大，易同质化

解法二：业务素材库召回

✅ 风格贴近业务调性，参考价值高
❌ 新业务/冷启动素材积累有限

解法三：通用素材模板库

✅ 去业务、跨业务复用
✅ 新业务也能直接复用
✅ 模板随时间持续积累

模板库构建的关键是去业务抽象化：把"618 狂欢购大标题"抽象成 headline、品牌 Logo 抽象成 logo、商品大图抽象成 hero_visual、"立即抢购"按钮抽象成 cta_button、"新品/热卖"贴片抽象成 badge。要避免描述具体颜色——否则用户指定颜色时会与模板冲突、导致配色混乱。

复利效应
三种解法互补叠加——模板库的价值随时间复利增长。

2.8画师 Agent：图片素材如何处理安全区域

业务硬要求：广告文字必须放在安全区域内，否则在不同手机屏幕会被平台 UI、点赞、评论框遮挡。直接给模型描述约束（"限制在多少比例以内"）行不通——模型空间控制精度不足，文案溢出、元素压线频发，超出安全区域比例超过 80%。

当前解法是"生成 → 评估 → 二次编辑"的小循环（Loop）。这里有个关键踩坑：最早的编辑提示词写"把文案放到红框中，同时把红框去掉"，结果模型把红框去掉后不知道红框在哪、彻底混淆；正确写法是"把它缩小一点、往某方向移动一下"这类与图片强关联的具体指令。

>80%

直接描述约束时·超安全区比例

<10%

生成+评估+二次编辑后·超安全区比例

方法论
把"空间控制"转化为"空间检测 + 局部修正"——用迭代（Loop）逼近目标。

2.9剪辑 Agent：理解素材，合成成片

三项职责：素材解析与重组（时间轴对齐与逻辑重组）、视听语言转化（转场、特效、字幕、音效）、质量把控与输出。核心三步工作流：

① 理解 Understand
解析分镜、识别素材、提取关键帧与音频节奏点

→

② 合成 Synthesize
多轨道混编、转场特效、动态字幕、音画同步

→

③ 成片 Finalize
渲染导出高清、自动适配多平台分辨率格式

最终执行者
剪辑 Agent 是整条链路的最终执行者——所有上游产出在这里汇聚成片。它还负责把业务元素融合进来（否则只是 AI 短片，不是广告）。

2.10质检 Agent：每个 Agent 都值得有一个评估者

通用评估模式：Agent 执行任务生成初步结果 → 质检 Agent 多维度打分与审查 → 通过则流转下一环，不通过则生成修改建议打回。部分 Agent 的评估维度：

被评估对象
核心评估维度

策划 Agent
广告目的和产品卖点提炼准确性、受众分析、情报信息利用合理性

文案 Agent
表达清晰度、卖点突出度、感染力、口语自然度、节奏感

编剧 Agent
脚本结构完整性、镜头可执行性、分镜清晰度、信息密度、时长合理性、转场连贯性

画师 Agent
事实准确性、风格一致性、目标受众契合度、情感匹配度、画面瑕疵等

过程中的评估保底线，成片后的归因提上限。—— 质检 Agent 的双层价值

2.11让 Agent 协作顺畅的三个关键

这三个原则听起来简单，但在实际搭建时很容易违反：

① 每个 Agent 只做一件事

保持单一职责原则，避免单个 Agent 承担过多复杂任务——能极大降低幻觉率，提高稳定性和可维护性。

② 上下游传结构化数据

Agent 之间传 JSON 等结构化格式，确保信息准确、下游易解析。图片 URL 等复杂内容塞进纯文本，容易传错导致系统崩溃。

③ 出了问题先调整输入

优先检查优化 Prompt 或上游输入，而不是急于改 Agent 核心逻辑或加 if-else 补丁——否则 Agent 会越来越不通用。

PART 3 · 端到端自动生成

实战推演：视频/图片素材的诞生全流程

以元宝 App 一次真实的素材生产任务为例，沉浸式体验从一句话需求，到多条可投放成片的全流程——看每个 Agent 如何接力，以及人在哪里介入。

3.1案例起点：一句话需求

用户原始输入
"帮我做 5 条元宝 App 的视频广告，社交方向，拍照识图功能，混剪形式。"

调度 Agent 先与用户交流理解需求（若不明确会反问），拆解出核心要素：产品主体（元宝 App）、主打功能（拍照识图）、投放场景（社交方向）、内容形式（混剪）、数量（5 条，做 A/B 测试）。随后按元宝业务定义好的流水线唤醒多智能体：策略 → 文案 → 编剧 → 画师 → 剪辑 依次执行。

3.2策略 Agent：分析参考素材，确定创意方向

策略 Agent 背后依赖底层知识库。它捞到一个优质参考素材（元宝"电子嘴替"社交回复文案）后，把 5 条视频拆成三类策略：

1 条仿制——对优质素材做文案改写（二创）

1 条复刻——文案直接沿用，替换画面

3 条原创——端到端从头生成，覆盖职场、社恐、恋爱、前任等不同人群方向

5 个任务随后被下游各 Agent 并发处理。

3.3文案 Agent：为每种策略撰写文案

文案 Agent 拿到策略任务后输出文案，关键在于营销手法结构。以仿制文案为例，可清晰拆出四段：

开头钩子（排比指令）：元宝帮我看看这句话怎么回 / 帮我分析他在想什么 / 帮我救救这尴尬的聊天

转折点：你的电子嘴替已上线

对比论证：之前对着屏幕发呆半小时……现在只要截图发给元宝，三秒钟拿到满分回复

收尾 CTA：免费的电子军师不要白不要，赶紧下载试试吧

差异点
这套营销手法，正是广告文案区别于其他文本创作任务的最大差异点。原创三条则组合了职场、社恐、恋爱等不同方向，保证多样性。

3.4编剧 Agent：接力创作结构化脚本

编剧把文案转化为可执行的视觉分镜。它从三个层面输出指导：

视觉风格

真人实拍、暖白色调、自然光、手机拍摄质感、9:16 / 1080×1920

分镜设计

按 Clip 分段（CL1-CL6）：开场吸引→痛点铺垫→功能展示→效果演示→收尾强化→行动号召，标注时长与画面策略

音频风格

BGM（轻快电子流行乐 BPM 110-120）、SFX（消息提示音/截图快门音）、配音（年轻女声，语速偏快、亲切活泼）

编剧不用写太细，把握大方向即可——每个镜头凸显什么、整体节奏与尺寸约束，输出后传给下游。

3.5画师 Agent：撰写提示词并生成视频

画师为每个视频片段写极其精细的提示词，包含首帧 Prompt（静态）和视频 Prompt（动态）。整体风格控制统一约束：主体角色"20-25 岁中国年轻女生，雾蓝色小猫刺绣卫衣"，情绪从纠结→惊喜→自信递进，画面约束"手机屏幕不可见、角色不说话、无背景音乐"。

随后调用对应模型 API 生成 CL1-CL6 六个片段（8/5/7/5/5/3 秒）。因为人物描述引用了参考图并强调"蓝色小猫卫衣"，生成结果的跨镜头角色一致性得到很好保持。

并发优势
速度的核心是并发——多个片段/多条素材同时执行，总耗时与单条相当。

3.6剪辑 Agent：混剪成片，添加业务元素

纯 AI 生成的片段直接拿来做广告"没有感觉"，因为缺少业务元素。剪辑 Agent 会决策哪些时间点需要添加业务元素——例如 13.03-14.45 秒插入"点击对话框图片图标、从相册上传聊天截图"的操作界面；14.45-24.83 秒展示"元宝对聊天截图的分析、回复建议和聊天剧本"的 App 内对话。这些交互画面都是 AI 端到端生成，并自动识别添加时间点与文案的一致性。

业务元素的价值
添加业务元素后，广告瞬间"真实感更强、可信度更高"——从 AI 短片变成真正的信息流广告。

3.7质检 Agent：片段级 + 成片级双层把关

片段级质检

画面质量检测、音频检测（错字漏字）、逻辑连贯性校验、异常即时阻断与自动重试——"早发现早修复"

成片级质检

全局终审、音画同步、核心信息完整度、品牌合规、多维度评分与归因——"归因分析+数据沉淀"

质检输出会给出多维度分数（音频质量、画面质量、视觉连贯性、声画一致性）、是否通过、问题项与说明，并归因到具体是哪个 Agent 导致的问题。例如某片段画面在展示手机聊天界面时出现文字乱码（00:06-00:08），归因为"生成模型对细节小字无法控制"——经验反哺：后续策划画面时尽量避免容易出错的小字画面。

3.8成品输出：一句话需求，到多条可投放素材

三大产出特征：多维脚本矩阵（单一需求裂变多视角脚本，覆盖多类受众）、视听素材齐备（智能匹配 BGM/音效、合成人物角色与动态字幕、音画同步）、多尺寸全适配（一次生成 16:9 / 9:16 / 1:1，满足抖音、视频号、朋友圈全域分发）。与传统方式对比：

3.9人在哪里介入？——Human-in-the-Loop 设计

是不是人全程都不用参与？并非绝对的 0 和 1。系统提供三种模式：

全自动模式——端到端无人工干预，适用低风险、高频次、标准化程度高的场景（审核完即交付）

半自动模式——AI 完成基础工作，人在关键节点（审批）介入，平衡效率与风控（现阶段大部分工作状态）

辅助模式——人主导流程，AI 作为副驾驶提供建议/草稿/数据，适用高创造性任务

设计选择
Human-in-the-Loop 不是系统的缺陷，而是设计选择——让人在最有价值的地方发挥作用。

PART 4 · Loop Engineering

迭代升级：基于多模态大模型的闭环迭代（Loop Engineering）

Agent 矩阵解决了"生产"，但还没解决"学习"——为什么有效？怎么复制？这一章讲如何让投放数据反哺生产，把效果好坏自动提炼成给 Agent 的"改稿意见"，跑通数据飞轮。

4.1爬坡循环：从"单任务质量"到"系统持续进化"

前面几层循环，关注的都是单个任务的执行质量与成功率；而真正关键的一层，是如何用业务的投放数据，让整个 Agent 系统的能力越用越强。这就是让系统持续进化的"爬坡循环"。

核心命题
投放后的数据不该沉没——要能反向提炼为"创意基因"，回流重塑 Agent 的后续生产策略。

4.2数据反哺生产的三条老路，各有硬伤

路线
做法
硬伤

BI 分析
人给视频打标签 + 统计分析
人的精力/标签维度有限；换业务就作废，泛化差

预测模型
训练深度学习模型给素材打分
黑盒——只诊断不开药，不告诉你哪里能改进，无指导意义

引导生成
把效果信号作为条件注入生成模型
训练成本太高；优秀模型多已闭源，碰不到参数

转念一想
既然多模态大模型越来越强，能不能让它代替人去理解素材——不断看素材、关联投放效果，最后总结出"制作经验/爆款公式"？

4.3核心方法：TextGrad 文本梯度下降

引入 TextGrad（文本梯度下降）思想：把投放效果的好坏构建成一种"损失"，再通过 TextGrad 把这个损失转化成一段自然语言的"修改意见"，反馈给大模型，让它自主修改分镜/文案经验。

对比几种方式到底在学什么：BI 在关联"效果 ↔ 标签"；预测模型/条件生成都在死磕模型参数；而大模型经验学习，是让 Agent（如编剧）学到"更好的分镜经验"，生成更好的分镜、赢得更好的效果。

一个好比喻
相当于给 AI 配了一个能根据市场反馈不断指导它改稿的制片人 / 导演——从而实现数据对生产的闭环反哺。

4.4落地踩坑：过拟合 → 用"正则化"约束经验抽象度

机器学习里参数更新依赖每次前向传播；但在视频生成场景，直接走这个流程会过拟合——损失不稳步下降，模型收敛到一些"太细的经验"，换个场景就失效。

解法：正则化思想
让大模型总结时不要拘泥于细节，更多总结"有实操性的公式性意见"或更抽象一层的概念。这样学到的经验更有效、可复制性更强。

4.5学到的经验靠谱吗？——四重校验防"瞎编"

大模型会产幻觉，学到的经验必须先自证靠谱。团队设计了多种验证方案：

人工抽样——检查经验是否 100% 有样本支撑（实测确实都有支撑，非胡编）

对照实验——用"有人出镜 vs 无人出镜"正负样本让它学，验证它能准确识别出强特征

统计检验——用规则在正负样本中出现的频率差，过滤掉"不自信"的规律（越靠右下角越自信）

机器学习验证——把特征编成 embedding 与视频预训练特征做同比预测，确认信息量与传统方法可比

一个有意思的洞察
为什么好经验会同时出现在正负样本里？因为一条视频的 3 秒完播往往是多个经验共同作用的结果；而且好经验一旦被发现，很快会被大量复刻。

4.6训练案例：3 秒完播率提升 4.21pp

把学到的"高 3 秒完播经验"注入编剧 Agent后，业务侧评估反馈相当正向——很大比例是非通识性洞察（排除常识后仍让业务眼前一亮的新颖结论）。一个代表性结果：

4.7知识如何安全地融入系统

学到的经验不是直接写死，而是构建配对数据、动态调整一个"知识库"——它由大模型基于训练样本总结，但融入前需要经过一次人工审核校验，是定期离线流程，而非"大模型说什么就是什么"的实时黑盒。

数据飞轮
完整跑通"生产 → 投放 → 归因 → 调优 → 再生产"的工程闭环——数据不再沉没，而是变成持续复利的创意资产。

PART 5 · 工程落地

工程实现：驾驭工程落地的关键技术点

如何把 Agent 矩阵与素材分析能力真正工程化、跨业务复用？分享人给出三条核心理念。

5.1理念一：每个业务独立调度 Agent

不追求一个"通用大脑"动态规划一切，而是每个业务有自己独立的调度 Agent、独立的业务专属流程——用确定性换可靠性，避免动态规划的不可控与高延迟。

5.2理念二：通用 Agent 能力层 + 业务 Harness 环境

搭建通用的 Agent 能力层（文案生成、分镜策划、提示词撰写等核心能力与业务无关），再叠加业务专属的 Harness 环境去适配不同场景——相当于"实例化"一个新 Agent 来支持对应业务。业务 Harness 包含：

业务知识——卖点、人群画像、品牌调性

投放数据——历史素材、体量规律等

风格规范——禁用词、禁用提示词/文案/视觉风格

经验规则——业务循环沉淀的经验、质检要求

专属资产库——只有植入业务信息，视频才从"AI 短片"变成真正的信息流广告

复用逻辑
通用能力重点建设，业务侧只需配置信息即可快速适配新场景。

5.3理念三：Workflow + Agent 节点混合编排

Agent 不是孤立单点，而是嵌套在 Workflow 里的能力。Workflow 流程清晰、步骤明确、稳定可控；但它的节点也可以是 Agent。核心做法是在 Workflow 中混合编排 Agent 节点：

Workflow 是骨架，支撑起业务的下限，确保流程稳定靠谱；Agent 是灵魂，决定创意的上限，确保灵活。只用 Workflow 处理不了复杂逻辑，只用 Agent 又太灵活、链路易走偏。

务实之道
两者有机结合，才是当前工业级规模化生产最务实的做法——不必迷恋"纯 Agent 驱动"的完美。

PART 7 · 展望 & Q&A

未来展望与 Q&A 精选

投放/分析/制作三 Agent 联合的全自动闭环终局，这套范式的边界，以及给想上手的同学的四步走指南。

7.1终局图景：每人一个"私人广告创意部"

素材生产 Agent 只是庞大版图的冰山一角。未来的信息流广告，运营人员只需配置投放预算与 ROI，剩下的交给协同网络：情报 Agent 爬取素材、分析爆款趋势 → 素材生产 Agent 矩阵 自动产出图片/视频 → 广告创建 Agent 无缝完成账户搭建、素材上传与批量创建 → 运营 Agent 盯盘调价、关停低效广告 → 数据分析 Agent 沉淀数据、反哺下一轮生产。

尚在搭建中
这套全自动闭环目前还未落地，但团队相信流程一定能跑通——落地后将颠覆现有投放模式，为业务增长释放难以想象的生产力。

7.2范式的边界：不止于广告

"多智能体协作 + Harness 工程 + Loop Engineering 闭环学习"绝不只能用于广告，可拓展到任何复杂知识工作领域（软件工程、内容生产、金融/数据科学等）。判断能否套用，看三点：

能明确输入输出——各环节输入输出清晰，就能定义每一个 Agent

Agent 可专业化——赋予专业背景、系统提示词、专属工具与能力边界，实现精细分工

有可量化指标——有投放/量化评估指标就能构建闭环反哺；没有闭环也 OK，先搭生产管线

7.3上手指南：四步走

7.4Q&A 精选

Q1 · 怎么降低素材的"AI 感"？

跟模型强挂钩：图片一律用最好的闭源生图模型（单张几毛到一块多，成本可控），不在提示词上过度下功夫——闭源模型 AI 感已大幅降低。脚本层面则要先构建营销手法库/风格库，选定风格再生成脚本；历史样本多为人工撰写或网上爬取的优质脚本，AI 感天然更低。

Q2 · 素材越来越卷，预算是变多了吗？

整体感觉确实越来越卷：既要质量又要数量，以前 1 万的量需 100 条，现在要求更高。外部供应商也都在用 AI，只是用法不同（当工具 vs 搭 Harness 环境自动生成），成本持续下降。预算不好判断，但"今天能产 1000 条，下月可能就要 2000 条"。

Q3 · 视频剪辑一定要加业务元素吗？人工参与吗？

必须加——没有业务信息就不是广告。目前这条链路不需要人工参与，展示的样本都是端到端生成，游戏互动画面、元宝交互画面等都是 AI 端到端生成，并能自动识别添加时间点与文案的一致性。

Q4 · 这套 Agent 的通用性如何？

通用性是"逐步剥离业务"打磨出来的：先在一两个业务（元宝、火龙漫剧）跑通，再把 Agent 抽象成通用能力。7 月已快速适配光子小游戏、腾讯视频动漫、Q 币等业务，个性化改造成本不高。

Q5 · 剪辑 Agent 会遇到和生成图片不一致的问题吗？

剪辑时图片/视频已 ready，不再做深层生成，所以不会二次生成图片。人物一致性问题在上游画师 Agent 就已优化；随着外部视频生成模型能力提升，只要给参考图、提示词够清楚，跨镜头一致性越来越好。

Q6 · 会给每个 Agent 都构建评测数据集吗？

不会全建——Agent 任务复杂，构建一个数据集可能要好几周且未必提升效果。只对比较明确的东西（如部分视频维度）建数据集；大部分仍靠人工评估一批样本后，调大模型使其评估与人工 align。

Q7 · Loop 学到的经验，怎么平衡"利用"与"探索/创造性"？

目前不追求绝对：会按已有经验制作一部分比例（如 5 条里 2 条用经验），同时保留创造性探索的比例（如 3 条探索），因为现阶段还需大量提升 Agent 能力。创造性来自"不完全依赖过去经验"，并通过离线流程持续丰富营销手法库、画面经验库等知识库。

Q8 · 具体如何让 Agent 学习经验？

就是 Part 4 的 Loop 算法：构建配对数据，动态调整一个"知识库"（由大模型基于训练样本总结，非人工编写）。它更像知识库但不全是，融入前还需一次人工审核校验——是定期离线流程，不是实时黑盒。
