# 无限画布（spec/canvas/spec.md）—— 工作台核心交互层

> 状态：**规划中（随 P1 工作台实现）** ｜ 用户 2026-08-13 确认：无限画布是重要环节

## 1. 为什么需要无限画布
工作台不只是"表单→生成→下载"，更是**创作空间**：
- 角色设定板：立绘/表情/多视图/人设卡 铺在画布上，拖拽对比、批注
- 分镜板：剧本→分镜帧→关键帧 串联成叙事流（P2 前置）
- 世界构建：角色/场景/物品/关系 用卡片+连线组织（喂给 P3 世界观）
- 管线可视化：Job 状态/阶段产物/依赖 直接铺在画布上（呼应"每层产物可见"）
- AI 协作：人在画布上画箭头/批注 → AI 理解意图精准改图（Cowart 模式）

## 2. 技术选型（工业主流）
| 方案 | 说明 | 选型 |
|---|---|---|
| **tldraw**（开源 SDK） | 无限画布事实标准；React 组件；支持自定义 shape/绑定/多选 | ✅ 首选 |
| Excalidraw | 手绘风、协作 | 备选 |
| Miro/Figma | 商业 | 不选（不开源） |
| 参考实现 | **Cowart**（tldraw+Codex，AI 改图指哪打哪）、**tldraw-sandbox**（画布+AI 代码终端）、@xpert-ai/plugin-canvas（画布+Agent workspace） | 借鉴 |

## 3. 形态（集成进工作台）
- 工作台主页 = 无限画布（tldraw 嵌入），而非纯表单流
- 每个角色一个"角色板"：人设卡卡片 + 立绘/表情/语音节点（可点击预览/重新生成）
- 左侧/顶部 = 工具面板（上传、生成、下载、Job 状态）
- 画布节点可绑定"阶段产物"：图（缩略图）、音（播放器）、JSON（预览）
- AI 协作：批注/框选 → 触发重新生成/局部修改（后续迭代，先做静态铺陈）

## 4. 边界
- ✅ 做：tldraw 画布嵌入、角色板/分镜板/世界板 模板、节点绑定产物预览、画布↔Job 状态联动
- ❌ 不做（首期）：AI 实时改图画布（Cowart 式，后置）、多人实时协作（后置）
