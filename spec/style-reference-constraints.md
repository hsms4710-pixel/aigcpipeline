# 2D 管线参考图约束清单（spec/style-reference-constraints.md）

> 日期：2026-08-13 ｜ 目的：回答"给后续资产生成的参考图需要哪些约束"，并解释为什么昨天几次画风尝试不理想。
> 依据：OpenAI 官方 image docs（多图参考）、社区 prompt 设计、生图.md（风格标杆库）、ComfyUI IP-Adapter 经验、本项目实测（v7-v10 系列）。

## 0. 为什么昨天几次画风尝试不理想（实测归因）
| 尝试 | 做法 | 不理想原因（归类） |
|---|---|---|
| v8/v9 --style-ref 单图/双图 | 阿米娅_1/2 立绘作参考 + 风格 prompt | ① 参考图=角色+风格混合，模型分不清"学风格"还是"复制角色"；② 阿米娅画风素淡，跨题材（精灵游侠）迁移弱；③ images.edit 无独立 style 通道 |
| style_attempts 2ref/3ref/1ref | 阿米娅 1/2/skin1 组合 | ④ 不同立绘（精英1/2/皮肤）风格有细微差异，混用被"平均"掉；⑤ "Do NOT copy"负向约束连带削弱风格 |
| compare_sheet 4 风格 | 纯文字风格词 | ⑥ 抽象风格词（"painterly cel-shading"）不如"点名已知风格"有效；⑦ 无参考图锁风格，纯 prompt 不稳定 |

**根因一句话**：单张/混用参考图 + 角色风格不分 + 抽象风格词 + 无"风格标杆库+反馈"机制 = 模型没有稳定可靠的风格锚。

## 1. 参考图约束清单（2D 管线，按优先级）
### A. 风格纯度（最重要）
- [ ] 一组参考图必须**同一画师/同一画风系列**（如全部唯@W 阿米娅系），**严禁跨画师混用**
- [ ] 参考图间风格特征一致：线稿粗细、上色方式、饱和度、光影、材质感
- [ ] 若风格有时期差异（同画师不同年），选同一时期的

### B. 角色信息与风格信息分离
- [ ] 风格参考图**尽量不含目标角色**（画师其他作品/无角色场景/局部五官）—— 最优
- [ ] 若必须用含角色图（如阿米娅立绘），prompt 必须**显式声明"只学线稿/上色/渲染技法，忽略角色、姿势、服装"**
- [ ] 理想配置：**风格参考图（1-2 张）** + **角色参考图（1 张，目标角色锚点）** 分离给，各司其职

### C. 画质与规格
- [ ] 高清 ≥1024，无压缩噪点、无水印、无文字、无 UI
- [ ] 构图干净：角色清晰、背景简单或无背景（便于提取线稿/上色特征）
- [ ] 姿态中性（正面/标准站姿/半身），避免复杂动作/极端透视干扰风格学习
- [ ] 图幅统一（尽量同比例），避免模型被构图带偏

### D. 数量与多样性
- [ ] 风格标杆库：**3-8 张**同画师作品（覆盖站姿/半身/表情），比单张稳
- [ ] 每次生图引用 **1-3 张**（OpenAI 多图引用上限内），不要一次给太多（稀释风格）
- [ ] 多样性用于覆盖风格细节（头发画法/衣服材质/上色），不用于引入不同画风

### E. 同题材匹配
- [ ] 参考图题材与目标角色相近时风格迁移更准（奇幻/精灵角色配 RPG/方舟画风；像素配像素）
- [ ] 角色类型（年龄/体态）、服装复杂度相近

### F. Prompt 约束（配合参考图）
- [ ] 给每张参考图分配明确角色："图1=风格基准，图2/3=同风格细节补充"
- [ ] 风格描述 = **点名已知风格**（"Arknights official art style" / "Octopath Traveler style"）+ 具体技法词（线稿粗细/赛璐璐/软笔触/饱和度）
- [ ] **避免过度负向约束**（"不要复制角色"改为"保留风格，换新角色"）
- [ ] 固定风格模板：固定部分=风格/色调/光影/构图；可变部分=主体/场景（生图.md 风格母版思想）

### G. 人工审核 + 反馈（机制约束）
- [ ] 每次生成后人工挑"风格达标"的**回填风格标杆库**（正反馈飞轮）
- [ ] "不达标"记录原因到 lessons_learned（哪类参考/prompt 无效），规避历史雷区
- [ ] 维护 preferences（用户偏好的风格特征）库

## 2. 落地动作（对照本项目）
1. **建风格标杆库** `reference/style-library/<画师-系列>/`：精选 3-8 张同画师图 + manifest（画师/来源/风格特征描述/是否含角色）
2. **分离式参考**：生图时 `--style-ref 风格图×1-3 + --ref 角色图`（角色锚点与风格参考分开）
3. **反馈飞轮**：审图通过 → 回填/更新 manifest 权重；不通过 → 记 `harness/memory/style/lessons-learned.md`
4. **Prompt 模板**：固定风格段 + 可变主体段（contracts/prompt-templates/）
5. **SD 轨道**：风格 LoRA + ControlNet（ComfyUI）作为最终锁死手段（见 comfyui-lora-plan.md）
