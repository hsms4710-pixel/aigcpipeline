# V1 Spec：语音管线（独立实践：TTS + RVC + 声音集训练）

> 选型基线：TECH-STACK.md ｜ 付费清单：env/api-costs.md

## 1. 目标
独立的角色语音管线，两条路线 + 一个增强层：
- **路线 A：零样本克隆**（快，3-10s 参考音）——原型/快速出音
- **路线 B：声音集训练定制 TTS**（稳定高质量，角色专属模型）——生产级
- **增强层：RVC 音色转换**（通用 TTS 情感 + RVC 音色）

## 2. 路线 B：声音集训练 TTS（用户关注的重点）
**数据来源**（"已有的声音集"）：
- 游戏/视觉小说提取的角色配音（有教程：VN 提取→清洗→微调）
- 客户/已有录音集（按脚本录制）
- 数据集构建工具：**zh-tts-mini-corpus**（预选文本 + 录音工具 → 导出 GPT-SoVITS/CosyVoice 数据集结构）

**训练/微调工具（2026 主流）**：
| 工具 | 数据量 | 特点 | 选型 |
|---|---|---|---|
| **GPT-SoVITS 微调** | 1-5min | 中文最强、98%+ 相似度；few-shot；**国内二次元角色生态成熟**（崩铁/原神/崩三/绝区零/蔚蓝档案全角色模型分享+整合包+AutoDL/Colab 教程+情感分类训练） | **首选（用户确认，二次元角色声音集主线）** |
| **CosyVoice 2 微调** | 3-10s 零样本 / 微调 | 阿里、情绪控制强 | 首选备选 |
| **Spark-TTS 微调** | 少样本 | 有游戏角色微调先例（genshin 角色包） | 备选 |
| **Qwen3-TTS 微调** | 少样本 | 2026 新、neural codec 12Hz、高表现力 | 前沿候选 |
| XTTS-v2 微调 | 6s 克隆 / 微调 | Coqui、多语言 | 备选 |
| Fish-Speech / OpenAudio | 大规模 | 多语言 | 备选 |

**管线（声音集 → 角色 TTS 模型）**：
```
角色声音集（VN 提取/录制/客户提供）
→ 数据清洗：人声分离（PyMSS/UVR5）、降噪、切分、标注（text）
→ 数据集构建（zh-tts-mini-corpus 或脚本）
→ 微调（GPT-SoVITS 或 CosyVoice2 等）→ 角色专属 TTS 模型
→ 推理：任意文本 → 角色语音（WAV + 字幕）
→ 模型存档（可复用/可分发，注意版权：只用自有/授权声音）
```

## 3. 增强层：RVC 音色转换
- 定位：音色转换（非 TTS），音色相似度最高（2026 实测 9.5），保留情感
- 用法：通用 TTS（火山/Azure，情感自然）→ RVC 转角色音色（5-10min 素材训练）
- 组合实测：自然度 90%+ vs TTS 单独 60-70%
- 开源活跃：RVC-Project WebUI 2.3.260718

## 5. 边界
- ✅ 做：零样本克隆、声音集微调、RVC 增强、数据清洗/标注工具、字幕导出、模型存档
- ❌ 不做：视频生成（P2）、ASR 识别（后置可选）、角色形象（P1）、评测（P5）
